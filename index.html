📲 Conectar WhatsApp
  1. Abra o WhatsApp no celular
  2. Toque em ⋮ → Aparelhos conectados
  3. Toque em Conectar aparelho
  4. Mire neste QR (demonstração)
🛠️ Produção com Evolution API (grátis, 5 min):
docker run -p 8080:8080 atendai/evolution-api
Crie uma instância, leia o QR real e cole o webhook do seu bot. O fluxo deste app é 100% compatível.
Meta WhatsApp Cloud API (oficial)
1. Crie um app em developers.facebook.com
2. Adicione o produto WhatsApp
3. Gere token + phone_number_id
4. Configure o webhook para /webhook com este mesmo motor de fluxo.
